# spending-tracker

A Python tool that reads a month of bank transactions, sorts each one
into a category, and charts where the money went.

## What it does
- Loads transactions from a CSV file
- Categorizes each purchase by keyword (ignoring capitalization)
- Totals spending by category and shows each as a percent of the month
- Draws a bar chart of the results
